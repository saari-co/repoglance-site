# Hosting, gate 1: resources and the workers.dev preview (2026-10-01)

Decision `site-hosting-007`. The maintainer answered gate 1 with "Yes,
create and deploy preview" and "Workers Paid" on 2026-10-01, for the
Cloudflare account Wrangler was signed into on this machine (the account
that also holds the dinkuskit and smokyworks databases). Gate 2, the custom
domain and its DNS record, was not touched.

## What was created

| Resource | Name | Note |
| --- | --- | --- |
| D1 database | `repoglance-site-cms` | fresh; EmDash ran its runtime migrations on the first request |
| R2 bucket | `repoglance-site-media` | empty |
| KV namespace | `repoglance-site-session` | auto-provisioned by `wrangler deploy` for the adapter's `SESSION` binding; unused |
| Worker | `repoglance-site` | version `dd515c0a-7638-440e-86ec-859fa5e5c04a`, cron `0 4 * * *`, workers.dev on, preview URLs off, no routes |

Identifiers (account, database, namespace) stay out of source: the D1 id
lives in ignored `.local/deploy.env`, and the deploy config
`dist/server/wrangler.production.json` is generated by
`scripts/prepare-deploy.mjs` with `REPOGLANCE_WORKERS_DEV=true` and no
custom domain. Bindings on the deployed Worker: `SESSION` (KV), `DB` (D1),
`MEDIA` (R2), `IMAGES`, `ASSETS`, `EMDASH_SITE_URL`, `LOADER`.

Preview: `https://repoglance-site.growfunkybeans.workers.dev` (temporary;
gate 2 attaches `repoglance.com`).

## Smoke of the live preview

| Request | Result |
| --- | --- |
| `GET /` | 200 `text/html`, `data-content-source="seed"`, band hero, feature row, band call to action, canonical `https://repoglance.com/` |
| `GET /testers`, `/testers/` | 200 from the seed, `data-page="testers"`, closing band, the Google Group link, no Play URL |
| `GET /_emdash`, `/_emdash/admin`, `/_emdash/api/setup`, `/%5Femdash/admin` | 404 `text/plain`, body `Not Found`, no redirect |
| `GET /nothing-here` | 404, the site's 404 page |
| `GET /robots.txt`, `/screenshots/home-widgets-540.webp`, `/og-image.png` | 200 with their content types |

The first request took about 18 s (cold start plus EmDash's migrations on
the fresh D1); later requests took about 0.1 to 1 s from Atlanta. Each
public request runs a D1 query; no edge caching is configured yet
(follow-up, not a blocker).

## Not done (later gates)

  D1, R2 and KV deletions, each a maintainer action.
